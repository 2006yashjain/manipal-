# NyayaSetu AI

**Evidence Intelligence for Multi-Party Consumer Disputes**

> Turn a confusing consumer dispute into a structured, evidence-backed case.

*24-Hour Legal Hackathon • Prototype Demo*

---

## 🎯 Stage 1 Objectives & Deliverables
- **Landing Experience**: High-level problem visualization of the 5-node multi-party transaction chain (`Consumer` → `Marketplace` → `Seller` → `Payment Provider` → `Logistics Provider`).
- **Role Gate**: Role selection between **Consumer** (public case intake) and **Official / Reviewer** (restricted demo workspace).
- **Consumer Intake Engine**:
  - Transaction metadata collection (`Platform`, `Seller`, `Order ID`, `Date`, `Amount`).
  - Narrative story intake in plain language with no legal jargon required.
  - 3 PRD MVP issue category selectors.
  - Multi-remedy preference selection.
  - Optional multi-party entity tagging for future Transaction Truth Graphing.
  - Required legal safety consent agreement.
- **Record Completeness Checklist**: Real-time intake readiness status (Story, Transaction, Issue, Remedy, Evidence Upcoming).
- **Case Summary Dossier Preview**: Structured review card with synthetic demo scenario autofill.
- **Provenance Foundation Architecture**: Ready for multi-source validation in subsequent stages (`Consumer reported`, `Document supported`, `Disputed`, `Inferred`, `Unknown`).
